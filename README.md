## 📖 The Problem

Schools manage fee collection, pending dues, reminders, and financial reporting through **fragmented manual processes** — registers, WhatsApp messages, spreadsheets. Parents have no clear view of their child's fee status or payment history.

## 💡 The Solution

**ShikshaOne** connects school admins and parents on a single platform:

```
School financial data  →  Centralized management  →  AI insights  →  Actionable decisions
```

> ⚠️ Not a generic school ERP. Laser-focused on: **Fee Management + Financial Intelligence + Parent Communication.**

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router) + TypeScript
- **Styling:** Tailwind CSS + shadcn/ui
- **Animation:** Framer Motion
- **Data:** Mock data (no backend yet)
- **Deployment:** Vercel

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/DishantBhere/shiksha1.git
cd shiksha1

# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) 🎉
